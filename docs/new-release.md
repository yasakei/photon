# Updating versioning for package managers and whatnot

- App metainfo: `extra/linux/dev.photon.photon.metainfo.xml`
- macOS plist (`CFBundleShortVersionString`): `extra/macos/Photon.app/Contents/Info.plist`
- Rust: `Cargo.toml`
- Obviously changelog: `CHANGELOG.md`
- RPM spec: `photon.spec`
- Windows wix spec (`<Product [...] Version=X.X.X>`): `extra/windows/wix/photon.wxs`
